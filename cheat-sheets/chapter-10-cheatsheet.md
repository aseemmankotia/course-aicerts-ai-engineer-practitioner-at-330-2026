# Chapter 10 Cheat Sheet: Exam Simulation & Time Management

## Time Budget
| Metric | Value |
|---|---|
| Total questions | 50 |
| Total time | 90 minutes |
| Average time/question | 1.8 min (108 sec) |
| Recommended review buffer | 10-15 min reserved for flagged questions |
| Suggested first-pass pace | ~70 min for 50 questions, leaving ~20 min buffer |

## Flagging Decision Table
| Situation | Action |
|---|---|
| Confident answer | Select, move on |
| Unsure, spent <2 min | Select best guess, flag, move on |
| Unsure, spent >3 min, no progress | Select best guess, flag immediately, move on |
| Out of time at end | Never leave blank — blank = guaranteed 0 |

## Question Phrasing Cues
| Phrase | Meaning |
|---|---|
| "(Select TWO)" / "(Select THREE)" | Multi-response — exact count required |
| "Which is the BEST solution?" (no select count) | Single-response — pick exactly one |
| "Choose the MOST appropriate" | Single-response |
| No select-count language present | Default to single-answer |

## Domain-Weighted Review Priority
1. Review flagged questions from the three 15%-weighted domains first (highest score impact per minute).
2. Review remaining flagged questions in any order if time allows.
3. Never spend final review minutes re-checking already-confident answers.

## Constraint-First Reading Strategy
1. Read the full scenario before looking at the options.
2. List explicit constraints: budget, compliance, performance/SLA, timeline, existing infrastructure.
3. Eliminate any option that violates a stated constraint.
4. Compare remaining options against the primary stated requirement — not the most feature-rich or complex one.

## Proctoring Checklist (Exam Day)
- Valid government-issued photo ID required.
- Clear desk/room: no notes, books, phones, secondary monitors.
- Room/webcam scan typically required before start.
- No other people permitted in the room.
- No external browser tabs, reference material, or unapproved scratch paper.

## Retake Policy Awareness
| Scenario | Typical Policy |
|---|---|
| First fail | Mandatory waiting period before retake |
| Retake cost | Fee applies unless bundle includes a retake voucher |
| Unlimited free retakes | Not standard — confirm bundle terms before test day |

## Elimination Strategy Summary
- Don't default to the most expensive or most complex option — neither is a reliable correctness signal.
- Watch for distractors that are technically valid but violate ONE stated constraint — these are the most commonly missed traps.
