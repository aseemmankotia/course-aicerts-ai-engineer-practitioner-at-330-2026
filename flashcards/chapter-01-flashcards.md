## Chapter 1: AI Engineering Foundations & Exam Blueprint — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | AT-330 exam: total questions and time limit? | 50 questions, 90 minutes. Exam tip: that's about 1.8 minutes per question — don't linger on any single item. |
| 2 | AT-330 passing score? | 35 out of 50 correct (70%). Exam tip: this is a raw score threshold, not a scaled score — count correct answers directly. |
| 3 | Supervised learning — one-line definition + example | Learns from labeled input-output pairs. Example: spam email classification using emails tagged spam/not-spam. |
| 4 | Unsupervised learning — one-line definition + example | Finds structure in unlabeled data. Example: customer segmentation via clustering with no predefined groups. |
| 5 | Reinforcement learning — one-line definition + example | Agent learns via rewards/penalties from environment interaction. Example: a game-playing agent improving through trial and error. |
| 6 | AI/ML engineer vs data scientist — key boundary? | Data scientist: exploratory analysis, feature engineering, initial modeling. AI/ML engineer: production pipelines, APIs, scaling, reliability. Exam tip: the exam tests who owns 'after the model works' tasks. |
| 7 | Standard ML workflow — six stages in order? | 1) Data collection 2) Preprocessing 3) Training 4) Evaluation 5) Deployment 6) Monitoring. Exam tip: questions often ask which stage a described activity belongs to. |
| 8 | Which ML workflow stage detects data drift after launch? | Monitoring. Exam tip: monitoring is the ONLY stage that runs continuously post-deployment — evaluation happens before deployment, not after. |
| 9 | What does the 'preprocessing' stage of the ML workflow involve? | Cleaning, transforming, and formatting raw data before training (e.g., handling missing values, normalization). Exam tip: distinguish preprocessing (pre-training) from monitoring (post-deployment). |
| 10 | Vendor-neutral AI engineering mindset vs vendor-specific certification — key difference? | Vendor-neutral = transferable concepts (workflow, learning types, lifecycle). Vendor-specific = one provider's tools/APIs. Exam tip: AT-330 tests concepts, not any single cloud's syntax. |
| 11 | Python prerequisite check: how do you compute the mean of a list without importing a library? | sum(data) / len(data). Exam tip: AT-330 assumes basic Python fluency — list operations, functions, and simple math are not taught in the course. |
| 12 | High-school statistics prerequisite: difference between mean and median? | Mean = sum of values / count. Median = middle value when sorted. Exam tip: median is less sensitive to outliers — relevant when reasoning about skewed data distributions in later chapters. |
