# Chapter 6 Lab: Applying Generative AI: Prompting, RAG, and Embeddings

**Estimated time:** 20 minutes

## Exercise

Build a minimal RAG pipeline: embed a small set of text documents with a sentence-transformer model, store vectors in an in-memory list, perform cosine-similarity retrieval, and feed the top result into an LLM prompt

## Key takeaway

RAG combines retrieval with generation to ground LLM outputs in current knowledge, and the exam expects you to choose RAG over fine-tuning when data changes frequently.
