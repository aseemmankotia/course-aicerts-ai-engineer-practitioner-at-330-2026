# Chapter 9 Lab: Building and Shipping AI Products: GUIs, APIs, and Deployment

**Estimated time:** 30 minutes

## Exercise

Build a Gradio app that wraps a Hugging Face sentiment-analysis pipeline with a text input and label output, then wrap the same model in a minimal FastAPI /predict endpoint and containerize it with a simple Dockerfile

## Key takeaway

Prototyping tools like Gradio and Streamlit and production tools like FastAPI and Docker serve different purposes in the AI shipping pipeline, and the exam tests picking the right tool for the right stage.
