# Chapter 8 Lab: Transfer Learning in Practice with the Hugging Face Ecosystem

**Estimated time:** 30 minutes

## Exercise

Fine-tune a pretrained distilbert-base-uncased model on a small text classification dataset using Hugging Face's Trainer API and the datasets library, then evaluate accuracy before and after fine-tuning

## Key takeaway

Transfer learning via Hugging Face's pretrained models and Trainer API is the fastest, most exam-relevant path from raw text to a working task-specific model.
