# Chapter 7 Lab: The NLP Pipeline: From Text to Transformer-Based Understanding

**Estimated time:** 25 minutes

## Exercise

Build a text classification pipeline with scikit-learn (TF-IDF plus logistic regression) on a sample sentiment dataset, then compare results to a pretrained transformer using Hugging Face's sentiment-analysis pipeline

## Key takeaway

Modern NLP has shifted from static bag-of-words and word-embedding pipelines to contextual transformer-based representations, and the exam tests both the classical pipeline and this shift.
